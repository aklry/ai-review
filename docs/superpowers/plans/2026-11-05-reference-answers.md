# 逐题反馈中的参考答案

日期：2026-11-05。

## 用户可见行为

每次提交回答后，Coach 在生成评分、亮点和改进建议的同一次模型调用中生成本题参考答案。主问题与追问都支持。

- 技术和设计题展示完整示范解法与答题要点，覆盖问题约束、方案取舍和验证方式。
- 个人经历题展示未填充的回答模板；具体项目、行动与结果全部以占位内容呈现，由用户核实填写，并附上待补充清单。
- 即时反馈标明刚刚回答的题目，避免与已经切换的下一题混淆。
- 历史逐题复盘可以读取保存的参考答案。旧记录继续可读，未保存参考答案时给出明确提示。

参考答案不是唯一有效解法。它不会自动写入简历或个人事实，也不会被后续评分、追问和报告作为用户已经回答的证据。

## 实现

共享 `referenceAnswer` 契约包含 `kind`、`content`、`keyPoints` 和 `missingFacts`。持久化读取允许缺失或 null，兼容旧反馈及 checkpoint；新 Coach 输出必须包含有效的参考答案，个人项目维度必须使用经历模板类型。

参考答案随评分在同一事务内保存到 `CoachingCue.referenceAnswer` 和回答的幂等响应中。重复提交复用原响应。历史查询和报告投影保留这个字段，供展示使用；构造后续模型输入及校验证据时移除它，防止教学材料被当成表现证据。

提示词版本更新为 `CoachAgent.reference-answer-v1:v1`，最大输出从 2800 调整为 4000 tokens，给参考答案留出空间。会增加输出 token 和一定等待时间，不额外发起独立的参考答案生成请求。

前端共用 `ReferenceAnswer.vue`，按纯文本展示正文、换行和代码，避免执行模型返回的 HTML。旧记录不自动补生成，也不额外触发付费调用。

## 验证

- `pnpm check`（格式、lint、类型检查）、`pnpm test`、`pnpm build` 均通过：195 个普通回归测试，6 个默认跳过用例。最终提示词调整后又完成 agent-core 构建、lint 和 43 个 Agent 回归测试。
- 本地 PostgreSQL 隔离 schema 的 4 项集成测试通过，包含主问题与追问的参考答案保存、会话恢复读取、逐题复盘及幂等响应。开发数据库已执行增量迁移。
- 前端测试覆盖参考正文的 HTML 转义、经历模板提示、旧记录缺失状态，以及提交后切换下一题时仍显示原题对应的参考答案。
- 初轮真实模型 smoke 为 19/20：`sys-cache` 同一强回答得到 5/3/5 分。检查输出发现部分判断追加了原标准未要求的实现细节；随后明确评分只依据题目标准，不以更详尽的参考答案为额外门槛。
- 第二轮为 20/20，但正文检查发现经历示例把“执行验证”扩写成成功结果，因此进一步要求个人经历内容采用未填充模板，不复制或扩写用户故事。
- 最终真实模型 smoke 为 **20/20**，20 条反馈均包含参考答案；4 个主题强/中/弱首次得分均为 5/3/1，重复评分分别为 `fe-race: 5/4/5`、`ai-eval: 5/5/5`、`sys-cache: 5/5/5`、`project-learning: 5/5/4`，最大分差均不超过 1 分。
- 最终模型返回标识为 `deepseek-flash`，评测耗时 122.110 秒。检查了全部 5 条个人经历参考正文，具体背景、行动和结果均改为待填占位。本轮为模型输出检查，不等于独立人工校准或事实准确性的普遍保证。

三轮结果均保留在 `.cache/evals/`：`rubric-2026-11-05T11-50-03.991Z.json`、`rubric-2026-11-05T11-53-52.587Z.json`、[最终输出](../../../.cache/evals/rubric-2026-11-05T11-58-04.819Z.json)。该目录被 Git 忽略。
