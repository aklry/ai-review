# 手机每日一练、错题收藏本与进步对比

日期：2026-11-16。先完成本实施文档，再执行开发。范围为第一轮三个功能，不包含通知、间隔复习算法、离线评分或新的语音分析。

## 用户流程

首页「每日一练」无需简历或 JD。每天按北京时间固定一道题，优先选择待练题，否则从现有规范题库轮换中文 L2 技术题。重复进入恢复同一题；完成后可再次作答。每日日期以服务端时间为准。

作答支持文字和现有录音转写，用户校正后主动提交。首次作答前不展示参考答案；提交后展示逐项反馈和参考答案。重答先收起历史反馈。

收藏本支持全部、收藏、待练、已掌握筛选。收藏与掌握状态独立；可取消收藏、标记待练或已掌握。存在未满足评分项的作答自动进入待练，后续满分不自动宣告掌握，由用户确认。完整模拟未结束时不能从收藏入口提前获取反馈。

历史复盘中可将具有规范评分快照的已评分主问题加入收藏本，并保留原题、原回答和原评分作为对比起点。无评分快照的旧题与追问不提供此入口。

进步页按题展示首次和最近一次回答的评分及逐项状态变化，区分新满足、退步、仍待加强；仅比较同一题目快照内的作答，不把不同难度或版本的分数混成能力趋势。单次作答显示「再答一次后查看对比」。

## 数据与接口

- 新增 LearningItem：用户键、唯一来源键、题目快照、语言、收藏状态、待练状态、作答记录 JSON、版本、处理租约、创建和更新时间。
- 新增 DailyLearning：用户键、北京时间日期、题目 ID；用户与日期唯一。并发进入通过数据库唯一约束收敛为同一题。
- 每日任务记录开始时的作答次数，只有新增作答才算当天完成，导入历史回答不计入当天完成。
- 每次作答保留请求 ID、时间、回答、完整反馈。以请求 ID 和版本防止重复提交；租约防止并发评分，过期可重试。响应丢失后先同步，已提交请求可返回原结果，不重复追加。
- 新增 /learning/daily、/learning/items、/learning/items/:id、/learning/items/:id/answers、/learning/import/:questionId；列表分页返回摘要，详情返回完整作答；共享 Zod 契约和 API client 校验响应。
- 继续沿用项目 local-user 身份语义，所有查询限定用户。此轮不实现登录。
- 评分复用现有 Coach 工作流、规范题快照、证据校验和用量记录。独立练习不创建虚假简历或完整面试，不写入面试分数统计。
- 本机草稿按 API、题目、作答版本隔离；录音复用现有组件并使用独立键。关键服务端数据可跨设备读取。

## 实施顺序

1. 共享契约、数据库增量迁移、服务和控制器，实现选题、收藏导入、筛选、幂等评分。
2. 共享客户端，手机学习列表、独立答题、对比页面，以及首页和复盘入口。
3. 验证日期边界、同日固定题、并发与重试、用户范围、延迟反馈保护、筛选和逐项对比；验证草稿与迟到响应。
4. 执行格式、lint、类型检查、相关测试、构建和 Capacitor 同步；记录结果及尚未执行的真机验收。

## 验收标准

- 无训练记录也可开始今日题；刷新和同日重复进入题目不变。
- 作答失败保留草稿，重复请求不增加记录，旧版本不能覆盖新结果。
- 复盘收藏可进入独立重答，重复收藏不重复导入；完整模拟未结束不能导入。
- 收藏与待练状态可独立管理，空列表、读取失败与分页有清晰交互。
- 两次回答可逐项比较，查看原文与依据；首次回答不伪造趋势。
- 真机另验麦克风权限、切后台、键盘、返回键、断网重试及真实 ASR/评分效果。

## 部署

维护者部署前执行 Prisma generate 和 migrate deploy，随后部署 API 与新 APK。开发过程不自动安装依赖，不对现有数据库执行迁移或重置，不调用付费模型做普通测试。数据库、真实模型和真机结果与本地自动检查分别记录。

```powershell
pnpm -F @interview-assistant/api prisma:generate
pnpm -F @interview-assistant/api exec prisma migrate deploy
pnpm build
pnpm -F @interview-assistant/mobile android:sync
```

新接口需和数据库迁移一起部署，否则新版手机学习入口会报错。沿用已有模型和 ASR 配置，没有新增模型密钥。
