# M1：规范题与逐项评分实施记录

日期：2026-11-04；最近验证：2026-11-05。对应 [优化路线 M1](../../2026-11-04-product-improvement-roadmap.md)。

## 实现范围

- 24 个规范题主题，四个能力维度各 6 个；每个主题按 L1/L2/L3 附加版本化约束。
- 应用依据简历、岗位分析、题目标签和会话种子选题，同场去重，标准八题保持 1/2/2/3 的维度配额。
- 新会话从题库选题，不调用模型自由改写题干；支持中文、英文和中英混合入口。旧的生成工作流保留，供已有调用和 checkpoint 兼容。
- 每道主问题保存题库身份、题目版本、约束、知识点、四项评分标准及五级评分锚点的快照。
- Coach 对每项给出已满足、未说明、存在错误或需要澄清，并关联当前回答原文；未说明的项目不伪造引用。
- 分数由应用计算：基础 1 分加已满足项数，不采信模型额外返回的总分。应用继续校验标准覆盖、引用和版本。模型的语义判断仍需通过评测与人工复核校准。
- 新报告采用 `rubric-v3`，旧的 `legacy-v1`、`evidence-v2` 保留。追问继续作为补充证据，不重复计分。
- 即时反馈和逐题复盘展示逐项依据、缺失信息及评分版本。
- 2026-11-05 另加入逐题参考答案；功能范围与新提示词的独立验证记录见 [参考答案实施记录](./2026-11-05-reference-answers.md)。下方 125 项全量结果对应加入该功能之前的评分基线。

## 模型评测

题库包含 72 个合成基础回答：每个主题的强、中、弱三类。18 个样例划为保留集，其他为开发集；标签由实现时拟定，尚未经独立人工标注。

另包含 5 个边界样例：简短正确、冗长错误、英文正确、诱导改变评分、结果依据不足。

```powershell
# 4 个主题的分层回答及重复评分：20 次逻辑调用
pnpm -F @interview-assistant/api eval:rubric

# 只测 5 个边界样例
$env:RUBRIC_EVAL_SCOPE = 'edges'
pnpm -F @interview-assistant/api eval:rubric

# 全部 72 个样例、48 次重复评分和 5 个边界样例：125 次逻辑调用
$env:RUBRIC_EVAL_SCOPE = 'full'
pnpm -F @interview-assistant/api eval:rubric
Remove-Item Env:RUBRIC_EVAL_SCOPE
```

命令读取服务端密钥并产生真实费用；修复或备用模型会增加实际尝试数。仅使用虚构数据，不写业务训练记录。结果写入 `.cache/evals/rubric-*.json`，包含每次评分和证据、分层区分、重复评分分布、模型及用量。失败也保存结果。

普通测试不会执行这些付费评测。`smoke`、`edges`、`full` 是分别运行的集合；不能以 smoke 的结果代替全题库验收。

遇到供应商 401/402/403 时不再切换同一账户的模型重试；评测保留首个失败，将后续探针标记为未请求。质量统计分别报告已测结果和覆盖数量，不把基础设施故障计作模型能力下降。

## 验证记录

- 最终普通回归通过：188 个测试；4 个数据库集成用例及 2 个真实模型入口按默认配置跳过，单独运行结果见下文。
- 本地 PostgreSQL 独立随机 schema：4 项集成测试通过，覆盖全部迁移、旧会话恢复、事务回滚，以及新题库快照/逐项反馈/报告/复盘的完整链路。
- 真实模型 smoke：20 次逻辑调用通过，四个主题强/中/弱分数均为 5/3/1；每个强回答三次评分一致。模型为 `deepseek-flash`，总耗时约 54 秒。这是小样本结果，不代表总体效果或 P95。
- 真实模型 edges：5 个边界样例通过。
- 首次全量评测：125 个用例中 124 个通过，1 个因模型总分与逐项判断不一致失败；据此将算分改为应用执行，并增加回归验证。
- 修复后全量复跑：前 25 个用例通过，包括此前失败的样例；随后 DeepSeek 持续返回 HTTP 402，其余 100 个用例未获得有效模型结果。此轮不能记为全量通过，结果保存在 `.cache/evals/rubric-2026-11-04T15-20-00.533Z.json`。
- [DeepSeek 官方错误说明](https://api-docs.deepseek.com/quick_start/error_codes/)将 HTTP 402 定义为余额不足。2026-11-04 遇到该错误后停止调用；新增的账户错误提前终止逻辑使用模拟 transport 验证。
- 2026-11-05 用户确认充值后，全量复跑 125/125 通过，无失败或跳过。24/24 个主题强弱区分正确，24/24 组重复评分最大分差不超过 1 分（20 组完全一致、4 组有 1 分波动）；5 个边界样例全部通过。模型返回 `deepseek-flash`，评测耗时 340.862 秒。此次覆盖 L2 合成样例，独立人工校准仍待完成。详见 [本轮评测与分歧记录](../../evaluations/2026-11-05-m1-rubric-evaluation.md)。
- 浏览器使用虚构数据核对逐项复盘的题干、标准、满足/缺失状态和证据展示；临时预览文件与服务已清理。
- 本地开发数据库已执行增量迁移；未重置业务数据。
- `pnpm check`（格式、lint、类型检查）、`pnpm test`、`pnpm build` 和 `git diff --check` 均通过。
