# 安卓端完整训练与录音答题设计

日期：2026-11-08。状态：用户已确认整体设计，进入实现。依赖由用户安装，禁止自动安装。

## 已确认的需求

- 安卓端具备电脑端现有的完整面试训练功能，可以独立完成训练，不再依赖电脑创建记录。
- 手机答题支持录音、转为文字、用户校正后提交，保留本机录音供逐题回听。
- 录音通过服务端调用可配置的语音识别服务转写。
- 手机端移除连接设置，直接使用构建配置的 API 地址；默认沿用现有生产服务器。

## 当前代码与差异

`apps/mobile` 是 Vue 3、Ionic Vue 和 Capacitor 8 客户端。已有未完成训练列表、接续答题、暂停后恢复、按题草稿、生成报告和简化复盘。`apps/desktop` 已有资料准备、岗位分析、新建训练、面试控制、详细复盘和专项练习。

两端使用相同服务端和 `local-user` 数据，继续沿用当前身份语义。本次无需修改面试记录和评分的数据库结构。

桌面语音转写依赖 Electron IPC 和 Windows 识别器，不能在 Android 复用。现有 API 仅接收文字回答，没有语音转写能力。Android 工程在当前工作区已存在且未跟踪；实施时保留现有构建配置，只调整本次需要的权限与文档，不覆盖用户已有工程。

## 方案选择

推荐保留独立移动端界面，复用共享契约、请求客户端和服务端业务接口；补充移动端专用流程与录音组件。手机继续采用适合触屏的单列界面，功能与电脑对齐。

直接嵌入桌面页面虽然搬迁较少，但包含 Element Plus、Electron 专用能力和宽屏布局。全面合并两端界面则会扩大改动范围。因此本次只把确实共用的 API 调用提取到 `packages/api-client`，避免两个客户端维护不同接口参数。

语音方案已选择服务端转写。手机系统识别的兼容性取决于 Android 版本和引擎；服务端转写可以复用同一录音，且不依赖手机安装特定识别器。

## 手机页面与功能

### 首页和历史

- 首页提供新建训练、继续未完成训练、最近记录与复盘入口。
- 无记录时直接引导准备简历和岗位，不再提示去电脑创建。
- 历史支持全部、进行中、待生成报告、已完成筛选及分页。
- 未测评的分数显示“未测评”，主问题和追问进度按现有规则展示。
- 保留手机已有训练和复盘链接，避免更新后旧链接失效。

### 准备训练与岗位分析

- 支持称呼、PDF/DOCX 简历上传（10 MB 上限）及手动粘贴简历文本。
- 展示上传进度、解析结果与错误，解析失败可切换手动文本。
- 支持目标岗位、公司、岗位描述，以及项目经历的 STAR 字段与量化结果。
- 调用现有岗位分析接口，轮询展示分析结果、能力要求、差距和准备建议；失败可重试。
- 保存分析任务 ID，页面重新打开时查询服务端恢复状态，离开页面后停止轮询，过期响应不覆盖当前训练。
- 新建训练的语言、轮次、难度、题数、逐题辅导/完整模拟及时间限制，与电脑端现有选项一致。

### 面试与控制

- 展示题目、主问题进度、追问标识、模式与剩余时间。
- 支持文字回答和录音转写，回答长度遵循现有 20,000 字契约。
- 提供暂停、继续、跳过、提前结束并生成报告；提前结束遵循现有后端允许条件。
- 录音和转写期间禁用会推进或切换当前题目的操作；切后台时停止录音并保存已取得的音频。
- 每次提交或控制后读取服务端权威状态；响应丢失时先同步再重试，避免重复推进。
- 草稿按 API、会话、题目隔离；另一设备推进后不把旧草稿填入新题。
- 逐题辅导展示完整评分、证据和参考答案；完整模拟继续遵守服务端延迟反馈规则。
- 保存上一题及其反馈的对应关系，录音和反馈不附到新题。

### 报告、复盘与专项练习

- 完整展示综合分、四维分、未测评状态、总结、优势、差距和七天计划。
- 主问题分组展示关联追问，包含原回答、评分项状态、理由、原文证据、参考答案、要点与待补充事实。
- 在手机录制过的题目可以回听和删除本机录音；其他设备没有的本地录音不伪装为可用。
- 支持查看参考答案的记录、评分异议提交及对应提示。
- 已完成训练从薄弱评分项进入专项练习，支持原题重答、案例练习、变式复测、三轮评分比较；练习也支持录音转写，录音按练习和阶段隔离。

## 固定 API 地址

## 录音与转写

### 手机录音

使用 WebView 的 `getUserMedia` 和 `MediaRecorder`，由 Capacitor 8 现有 WebChromeClient 触发 Android 运行时授权。Android 清单增加 `RECORD_AUDIO` 和 `MODIFY_AUDIO_SETTINGS`；不增加存储权限和后台录音服务。

每段最长三分钟，显示录音时长、停止按钮及明确状态；拒绝权限时保留文字输入。停止后以 IndexedDB 保存音频，标识包含 API、会话和题目，专项练习包含任务和阶段。录音可播放、重录和删除；只有成功保存新录音才替换旧录音。

页面卸载、切后台、题目变化和异常都释放麦克风、定时器与对象 URL；异步回调校验题目标识和组件代次。无法保存时允许当前页面回听，并明确告知本机保存失败。网络失败不能删除已保存录音。

转写由用户点击“转为文字”触发，仅发送选中的录音。将音频转换为 16 kHz、单声道、16-bit PCM WAV 后上传，以统一格式、限制体积并支持服务端校验时长。转写结果加入当前回答草稿，保留已有手写内容；用户可编辑，只有主动点击提交才触发评分。

录音仅在当前手机持久保存，不上传对象存储做跨设备同步。服务端为转写临时处理音频；训练、文字回答、报告和练习继续使用共享数据库。

### 服务端接口

新增 `POST /api/speech/transcriptions`，采用 multipart：`file` 为 WAV，`language` 为 `zh-CN`、`en-US` 或 `mixed`。返回现有响应信封中的 `{ text: string }`，使用共享 Zod 契约校验。

增加独立 Speech 模块，服务端通过可配置的兼容 `/audio/transcriptions` 的服务发送 multipart 音频，支持：

- `ASR_BASE_URL`：识别服务 API 根地址，例如包含 `/v1` 的服务根路径。
- `ASR_API_KEY`：服务端识别密钥；自建免密服务允许留空。
- `ASR_MODEL`：实际提供方支持的模型名。
- `ASR_TIMEOUT_MS`：有上限的转写超时，默认 120 秒。

不预设实际提供方、不复用 DeepSeek 文本模型密钥、不向 APK 写入识别凭据。缺少地址或模型时返回明确的“语音转写服务未配置”，文字训练和本地回听继续可用。

服务端限制上传不超过 6 MB，并检查 WAV 容器、PCM 格式、采样率、声道、数据长度及三分钟时长上限；仅信任经过校验的音频内容。上游失败、空文本、超时与配置错误返回可读信息，不回传密钥或上游原始响应，不在日志中记录音频和识别正文。内存缓冲仅用于本次请求，不持久化到业务库或 MinIO。

## 代码边界

- `packages/api-client`：新增资料准备、练习、参考答案记录、异议和语音接口；电脑端迁移到同一调用定义，保持原有行为。
- `packages/contracts`：语音响应和语言契约，沿用既有训练/练习契约。
- `apps/mobile/src`：首页/历史、准备流程、面试控制、复盘和专项练习，独立录音存储、音频转换及组件。
- `apps/api/src/speech`：上传入口、WAV 校验和识别服务适配；注册到 AppModule。
- `apps/mobile/android/app/src/main/AndroidManifest.xml`：麦克风相关权限。
- `.env.example`、README、移动端规划与构建说明：固定地址、识别服务配置、构建和验收步骤。

不迁移电脑端的 Windows 本机转写，不改现有评分算法和面试状态机。本次完成后只有手机语音转写需要部署新增 API 并配置识别服务。

## 验证与验收

1. 共享 API 测试验证参数、路径编码、上传与转写响应；电脑端既有测试继续通过。
2. 移动端测试覆盖新建资料与分析恢复、模式参数、暂停/跳过/提前结束、响应丢失同步、路由切换和草稿隔离。
3. 录音测试覆盖拒绝权限、三分钟停止、切后台、保存失败、题目切换、转写迟到、保留已有文本及按题回听/删除。
4. Speech 测试使用模拟识别服务，覆盖有效 WAV、伪造/超大/超时音频、缺配置、上游错误和空文本；不调用真实付费服务。
5. 执行格式、lint、类型检查、相关测试及移动端/服务端构建；更新前端后执行 Capacitor sync。具备 JDK 21/Android SDK 时构建 Debug APK，否则记录实际构建阻碍。
6. 浏览器以手机视口验证新建训练到报告、专项练习与历史筛选；无连接设置入口。真机验证系统权限、回听、锁屏/返回键及重新打开后的恢复，不能用浏览器测试代替真机结果。
7. 真实识别验收需服务端配置有效识别服务：手机录一段中文或英文，回听后转写，校正再提交；电脑端刷新后看到同一次文字回答和报告。本机原音只在录制手机回听。
